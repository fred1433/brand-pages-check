The owner wants a kind of section the library does not have: $ARGUMENTS

New sections are code, so they go through their developer's review. Do not write components here.
Instead, write a short request in plain English (what the section shows, where it would be used,
an example of its content from an existing page) and open it as a GitHub issue with
`gh issue create --title "New section: ..." --body "..."`. Tell the owner the issue link.
